# Pramaan docs

The Pramaan documentation site, built with Mintlify.

- Guides: `index.mdx`, `quickstart.mdx`
- API reference: generated by `node scripts/build-api.mjs` from https://api.pramaan.dev/openapi.json

Preview locally:

```bash
npx mint dev
```

Check before pushing:

```bash
npx mint validate
```
