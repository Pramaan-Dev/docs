Pramaan puts thousands of actions behind one API: web search, people and company data, email, texting, calls, payments, documents, media, connected apps and more. You name the action; Pramaan picks the source, checks the answer and charges once.

- A **superpower** is one action with a fixed request and result, such as `web.search` or `email.send`.
- A **mission** is a fixed sequence of superpowers that returns one business result, such as `company.research`.

## Three ways in

All three reach the same API and follow the same rules.

| Way in | Start with |
|---|---|
| MCP server | `PRAMAAN_API_KEY=... npx @pramaan/mcp` |
| TypeScript SDK | `npm install @pramaan/sdk` |
| HTTP | Base URL `https://api.pramaan.dev`, header `Authorization: Bearer <key>` |
